# 연세 어학당 · 한국어 배치고사 — 작동 MVP

배치고사(레벨/급수 배정) 플랫폼의 **동작하는 프로토타입(MVP)**.
학생 응시 → 자동채점 → 강사 루브릭 채점 → 관리자 분반까지 **하나의 인메모리 상태를 세 역할이 공유**하며 실제로 시뮬레이션됩니다.

## 파일

- **`index.html`** — 작동 MVP (실제 시뮬레이션). GitHub Pages로 배포되는 메인 화면.
- **`screens.html`** — 초기 정적 화면 목업 (23화면 쇼케이스, 참고용).
- **`mockup-artifact.html`** — 모바일 공유(Artifact)용 본문 추출본. `index.html`에서 자동 생성.

## 사용법

상단 바에서 역할 전환:

1. **🎓 학생 응시** — 연세대 한국어 앱 [시험] 탭에서 **학번·생년월일**로 로그인 → 어휘문법(수준 자동 판정) → 듣기·읽기 → 말하기(녹음)·쓰기 → 제출.
   어휘문법·듣기·읽기는 **제출 즉시 자동 채점**, 말하기·쓰기는 **채점 대기**.
2. **🖥️ 관리자·강사** — 우측 토글로 관리자/강사 전환.
   - **강사**: 제출된 말하기·쓰기가 채점 목록에 실제로 등장 → 루브릭 점수 입력·확정 (관리자 전용 기능은 🔒).
   - **관리자**: 채점 완료 학생을 분반 확정 → 총점·급수 자동 산정. 설정의 배점·커트라인을 바꾸면 계산에 즉시 반영.

`↻ 처음부터` 버튼으로 초기화. 상태는 인메모리라 새로고침 시 리셋됩니다.

## 채점 로직

- **자동채점**: 어휘문법·듣기·읽기 = (정답 수 / 문항 수) × 영역 배점
- **적응형**: 어휘문법 정답률로 수준(초/중/고급) 판정 → 이후 영역 난이도 결정 (학생 비노출)
- **인간채점**: 연세대 공식 채점 구인(3점 척도). 말하기 = 내용·조직·표현·전달 **8개 세부 구인 × 3점 = 24점/문항**, 쓰기 = 내용·조직·표현 **7개 세부 구인 × 3점 = 21점/문항**. 문항별 채점 합산 → 영역 배점으로 환산, AI 가채점과 비교(관리자 전용)
- **종합**: 5영역 합산(기본) → 급수 커트라인으로 급수·반 배정

구현: 단일 HTML + 내장 CSS/JS/SVG. 외부 의존성 없음(폰트만 CDN).
